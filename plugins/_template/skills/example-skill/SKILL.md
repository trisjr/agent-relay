# Example skill

Every skill lives in its own directory under `skills/` and needs a `SKILL.md` with frontmatter:

- `name`: must match the directory name (kebab-case).
- `description`: one sentence in English, saying what the skill does and when the agent should use it.

The body tells the agent how to perform the task: list concrete steps, constraints, and acceptance criteria. Keep it short, imperative, and specific. Replace this file with your real skill and delete anything you do not need.
